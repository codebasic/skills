# AI 동향 보고서

AI 신모델 출시·업데이트 소식을 조사해 비교표 중심의 한국어 동향 보고서를 만드는 절차다. 데일리 브리핑, 특정 모델 심층 조사, 주간 동향 정리에 모두 쓴다. 도구 종류에 의존하지 않는다 — 웹 검색 도구(web_search 등)와 페이지 본문 추출 도구(web_extract 등)만 있으면 된다.

## When to Use

- "AI 소식/동향 브리핑·보고서", "새 모델 뭐 나왔어", "GPT/Gemini/Claude/GLM 비교" 류 요청
- 특정 신모델의 성능·가격·라이선스 확인 요청
- Don't use for: 단일 모델의 기술 사양만 묻는 경우(보고서 형식 없이 답), 증시/산업 동향 등 모델 외 AI 뉴스

## 조사 절차

1. **소식 수집**: 웹 검색을 여러 쿼리로 돌린다. 예: "new LLM release", "<모델명> announcement", 랩 이름(OpenAI, Anthropic, Google Gemini, Meta Llama, xAI Grok, Mistral, DeepSeek, Qwen, Z.ai GLM, Moonshot Kimi, MiniMax) + release. 최근 24시간 위주. 기간 요구가 없으면 최근 2~3일을 보완 조사한다.
2. **수치 확인(중점 항목)**: 각 소식 모델의
   - AA Intelligence Index — 점수·순위·**버전(v4.x)** 필수
   - API 가격 — 입력/출력 per 1M 토큰
   - 출력 속도 — Artificial Analysis median output tok/s
   - 라이선스 — MIT/Apache 2.0/Llama 커뮤니티 등 종류 명시, 클로즈드면 '클로즈드'
   확인 순서: artificialanalysis.ai/models 메인 차트 → 못 읽으면 artificialanalysis.ai/models/<모델명> 개별 페이지, llm-stats.com, 공식 발표 페이지를 추출 도구로 직접 확인.
3. **지수 버전 변경 감지(필수)**: AA 지수 버전을 항상 확인한다. 전 모델 점수가 일괄 이동 등 체계적 변화가 있으면 지수 버전이 바뀐 것 — 보고서에 '📊 지수 변경 해설' 섹션 추가: (1) 이전→새 버전명 (2) 변경 내용(평가 항목 교체/재가중/채점 강건성 — artificialanalysis.ai/articles나 changelog 확인) (3) 순위 재편 여부 (4) 버전 간 수치 직접 비교 금지 주의. 버전 동일 시 생략.
4. **중국계 서비스 현황(표 포함 시 매일 갱신)**: Z.ai(GLM/GLM Coding Plan), DeepSeek, Alibaba(Qwen/Model Studio), Moonshot(Kimi), MiniMax의 현재 가격과 진행 중 프로모션·할인을 **당일 기준으로 재조사**한다. 이전 보고서 값 복사 금지 — 프로모션은 주 단위로 바뀐다. 못 확인하면 '조사 필요', 변동 없음이 확인되면 '변동 없음' 명시.
5. **토론 수집**: 오늘 소식 모델에 대해 "site:x.com <모델명>", "<모델명> twitter reaction" 류 쿼리로 X 토론 2~4개를 찾는다. 리서처·개발자의 실질적 평가(벤치마크 의심, 실사용 후기, 논쟁) 위주, 홍보성 포스트 제외. 링크+작성자 포함. 부족하면 블로그/레딧으로 대체.

## 출력 형식

짧은 헤더(날짜) 후 바로 본문. 장황한 서론 금지. 3분 안에 읽히는 분량. 순서:

1. **서두 오늘 소식 요약 표**: 모델 | 랩 | AA 지수(버전) | 출력 속도 (tok/s) | 입력가($/1M) | 출력가($/1M) | 라이선스 | 한줄평
2. (지수 변경 시) 📊 지수 변경 해설
3. 소식 불릿 — 모델명·발표 주체·핵심 내용·출처 URL
4. **미국 vs 중국 성능 비교 표**: 모델 | 진영 | AA 지수(버전) | 출력 속도 (tok/s) | 입력가($/1M) | 출력가($/1M) | 라이선스. 양 진영 최신 플래그십을 한 표에(5~12행), 각 진영 최고점 모델 굵게. 표 아래 한 줄 분석: 진영 간 격차(같은 버전 내), 오픈웨이트 비중, 속도-가성비 하이라이트.
5. **중국계 서비스 현황 표**: 서비스/모델 | 구독·API 가격 | 프로모션·할인(기간 명시) | 라이선스/비고
6. X(트위터) 토론
7. 한 줄 정리

요청 범위가 좁으면(단일 모델 등) 해당 항목 표만 축소해 쓴다 — 불릿·표 구조와 정직 규칙은 유지.

## 정직 규칙

- **당일 확인 못 한 수치는 추측 금지 — '조사 필요'로 명시**한다. 이전 날짜 값을 오늘 값처럼 쓰지 않는다.
- **한 표 안의 모든 AA 지수는 동일 버전**이어야 한다. 버전이 섞이면 해당 칸을 '조사 필요'로 표기한다.
- 검색 결과의 날짜를 확인한다. 오래된 기사의 신모델 소식을 오늘 소식으로 쓰지 않는다.

## Pitfalls

- artificialanalysis.ai 차트는 JS 렌더라 검색 스니펫만으로 점수를 읽었다고 판단하지 않는다 — 개별 모델 페이지를 추출 도구로 직접 확인한다.
- 지수 버전 간 점수 비교(예: v4.1의 42 vs v4.2의 38)는 무의미하다. 평가 항목이 바뀌었으므로 절대 비교하지 않는다.
- 모델 스냅샷/프리뷰(예: "-exp", "-preview")는 정식 버전과 가격·라이선스가 다를 수 있다 — 명칭을 정확히 구분해 표기한다.
- 프로모션 가격과 정가를 구분한다. 프로모션은 종료일을 확인해 명시한다.

## Verification

- 보고서의 모든 수치(지수·속도·가격)에 대해 출처 URL을 소급 확인 가능한지 점검한다. 출처 없는 수치는 '조사 필요'로 바꾼다.
- 표 내 AA 지수 버전 혼입 여부, 굵은 최고점 모델이 실제 최고점인지 재확인한다.
- 섹션 순서가 위 형식과 일치하는지 확인한다.
