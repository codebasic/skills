# 데이터 분할과 전처리

예측 시점에 사용할 수 있는 정보만으로 재현 가능한 훈련·검증·시험 데이터를 준비합니다. 특정 교재나 프레임워크를 전제하지 않습니다.

## 작업 경계

- 분할과 전처리의 적합 범위를 담당합니다. 지표·비교 설계는 [ml-model-evaluation](../ml-model-evaluation/SKILL.md), 학습 결과의 원인 진단은 [ml-training-diagnostics](../ml-training-diagnostics/SKILL.md)를 필요할 때 함께 사용합니다.
- 시계열 윈도우·리샘플링·예측 모델 구현은 [timeseries](../timeseries/SKILL.md), Keras API 구현은 [keras](../keras/SKILL.md), 기존 환경 선택은 [pydeep](../pydeep/SKILL.md)의 범위입니다. 단순히 해당 라이브러리를 사용한다는 이유로 이 스킬을 추가하지 않습니다.

## 준비 절차

1. 예측 대상, 예측 시점, 관측 단위와 독립 단위를 확인합니다. 같은 사람·장비·원본 이미지에서 나온 행, 중복 표본, 시간상 인접한 윈도우를 찾습니다. 정답 이후에 생기는 변수나 정답을 대신 알려주는 필드를 구분합니다.
2. 실제 사용 상황에 맞춰 분할합니다. 독립 표본이면 무작위 분할, 새 사람·장비로 일반화하면 그룹 분할, 미래 예측이면 시간 순서 분할을 선택합니다. 계층화는 클래스 비율을 유지할 뿐 그룹·시간 누수를 해결하지 않습니다. 윈도우 경계의 정답 시점과 중첩을 확인하고 필요한 간격은 예측 지평과 실제 의존성에 근거해 정합니다.
3. 결측 대체, 표준화, 범주 사전, 특징 선택, PCA, 표적 인코딩 등 데이터에서 배우는 변환은 훈련 부분에서만 fit합니다. 검증·시험에는 transform만 적용합니다. 교차 검증이면 각 fold의 훈련 부분에서 다시 fit합니다. Pipeline/ColumnTransformer 등으로 이 경계를 코드에 포함합니다. 단위 변환·고정 상수 나눗셈처럼 표본 통계를 배우지 않는 변환과 구분합니다.
4. 증강·오버샘플링은 분할 후 훈련 부분에만 적용합니다. 표적 인코딩의 훈련 특징도 out-of-fold 방식 등으로 자기 정답 노출을 막습니다. 데이터가 부족해도 시험 데이터를 전처리·모델 선택에 재사용하지 않습니다.
5. 분할 인덱스·시드·데이터 버전·변환 설정을 기록하고, 행·그룹 교집합, 시간 범위, 클래스 수, fit 호출 위치를 검증합니다. 개인정보가 있는 원본 행을 보고서에 불필요하게 복사하지 않습니다.

## 결과물

분할 기준과 그 이유, 사용 가능한 특징과 제외 근거, fit/transform 경계가 보이는 코드 또는 수정 diff, 분할별 표본·그룹·시간 요약과 실제 확인 결과를 제공합니다. 실행하지 못했다면 정적 점검과 실행 검증을 구분합니다. 누수가 의심되면 근거 필드·코드 위치를 지적하고 실제 생성 시점을 확인하기 전에는 누수라고 단정하지 않습니다.
